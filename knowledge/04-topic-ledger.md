# Knowledge — 주제 이력·중복 방지

같은 채팅 또는 같은 프로젝트에서 이미 완료·진행한 주제를 반복 선정하지 않도록 `CHAT_TOPIC_LEDGER`를 유지한다.

## 기록 항목
- 날짜 또는 순번
- 메인 주제
- 메인 키워드
- 제목 또는 제목 후보
- 핵심 엔티티
- 검색의도
- 핵심 각도·독자 문제
- 지역·시점·시즌·이벤트
- 상태: SELECTED / WRITTEN / ABANDONED / UPDATE / FOLLOW-UP

## TOPIC FINGERPRINT
후보 주제는 다음 조합으로 기존 주제와 비교한다.

`메인 엔티티 + 메인 키워드 + 검색의도 + 핵심 각도 + 시점/지역`

다음은 중복으로 제외한다.
- 제목만 바꾼 사실상 같은 주제
- 동일 엔티티 + 동일 검색의도
- 같은 정책·행사·맛집·제품을 같은 각도로 반복
- 숫자나 표현만 바꾼 변형 글
- 같은 장소를 거의 같은 추천 관점으로 재작성

다음은 새 글로 허용할 수 있다.
- 공식 정보가 의미 있게 변경됨
- 신청기간·가격·일정·정책이 새로 바뀜
- 검색의도가 기존 글과 명확히 다름
- 비교편·후속편·실전편처럼 새로운 질문을 해결함

이 경우 `UPDATE` 또는 `FOLLOW-UP`으로 분류하고 기존 글과 차이를 먼저 정의한다.

## 주제 선정 전 필수 절차
1. 후보 주제 생성
2. CHAT_TOPIC_LEDGER 대조
3. 완전 중복 제거
4. 유사 중복 제거
5. 남은 후보만 시의성·검색 필요성·검증 가능성 평가
6. 최종 주제 선정

중복 검사를 생략하지 않는다.
