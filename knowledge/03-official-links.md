# Knowledge — 독자용 공식 링크

게시용 원고 작성 시 **독자가 실제 행동하거나 공식 원문을 확인하는 데 필요한 링크**가 있는지 검사한다.

링크는 장식이나 출처 나열이 아니라 다음 행동을 돕기 위해 사용한다.

## 우선순위

**실제 신청·예약·조회·납부 페이지 → 직접 운영기관 안내 → 정부·공공기관·법령 원문 → 제조사·기업 공식 페이지 → 신뢰 가능한 보조자료**

우선 연결 대상:
- 신청
- 자격조회
- 예약
- 요금확인
- 납부
- 잔여석·재고조회
- 서류발급
- 법령원문
- 공식공고
- 위치·교통
- 공식사양
- 고객센터·분쟁조정·상담

가능하면 홈페이지 메인보다 **해당 행동을 바로 할 수 있는 직접 페이지**를 연결한다.

---

# 링크 문구

`여기 클릭`, `바로가기`처럼 목적이 불분명한 표현보다 다음처럼 작성한다.
- 복지로에서 신청하기
- 국가법령정보센터에서 법령 확인
- 코레일 승차권 예매
- 공식 고객센터 안내 확인

링크 문구만 보고도 무엇을 하게 되는지 이해할 수 있어야 한다.

---

# 최종 출력 링크 문법 — 필수

독자용 공식 링크는 최종 원고에서 **클릭 가능한 마크다운 링크**로 출력한다.

형식:

`[독자가 보는 링크 문구](https://실제-검증된-URL)`

예:

`[2차 섬 여행비 지원 공식 페이지](https://www.visitisland.kr/promotion2)`

금지:
- 링크 문구만 쓰고 URL을 숨기기
- 내부 검색 ID나 도구 전용 링크 형식 사용
- 검증하지 않은 URL 추정 생성
- 글쓰기 블록 안에서 링크가 사라지는 방식 사용

사용자 화면에서 링크 문구가 클릭 가능하게 렌더링되지 않으면 **링크 삽입 완료로 판정하지 않는다.**

---

# 링크 수

모든 사실에 링크를 붙이지 않는다.
같은 링크를 반복하지 않는다.
조사 출처 전체를 게시용 링크로 바꾸지 않는다.

출처와 독자용 링크를 구분한다.

- **출처:** 작성자의 검증 자료
- **독자용 링크:** 신청·조회·예약·원문 확인 등 다음 행동을 위한 페이지

링크가 없어도 본문만으로 핵심 내용을 이해할 수 있어야 한다.

---

# 삽입 전 LINK VERIFY

각 링크는 최종 원고에 넣기 전에 실제로 열어 확인한다.

1. 현재 접속 가능한가
2. 404·오류·종료 페이지가 아닌가
3. 리다이렉트 후 도착 페이지가 원래 목적과 같은가
4. 최신 연도·현재 제도·현재 상품·현재 행사인가
5. 신청 페이지와 안내 페이지를 혼동하지 않았는가
6. 지역·대상·사업이 맞는가
7. 종료된 사업이나 전년도 페이지가 아닌가
8. 홈페이지 메인보다 더 직접적인 공식 페이지가 있는가
9. 링크 문구와 실제 페이지 목적이 일치하는가
10. 로그인·앱 전용 등 이용 제한이 있으면 본문에서 필요한 만큼만 알리는가

정확한 공식 페이지를 확인하지 못하면 URL을 임의로 만들지 않고 링크를 생략한다.

---

# 게시 직전 LINK RECHECK

5단계 최종 확정 직전에 독자용 링크를 다시 확인한다.

- 링크가 여전히 열리는가
- 신청·예약·행사가 종료되지 않았는가
- 마감일·연도·사업명이 본문과 일치하는가
- 다른 페이지로 변경되거나 리다이렉트되지 않았는가
- 링크 문구와 실제 목적이 일치하는가

SmartEditor·브라우저 자동화로 실제 편집하는 경우에는 링크를 삽입한 뒤 한 번 더 확인한다.

- 링크 문구와 실제 목적지가 유지됐는가
- 네이버 플레이스는 정확한 상호·주소·지점인가
- 방송·YouTube는 관련 개별 회차·영상인가
- 편집 과정에서 URL이 삭제·변형되지 않았는가
- 가능하면 새 탭에서 실제로 열리는가

이 편집 후 확인은 knowledge/12-mobile-publishing-ux.md의 SmartEditor 링크 재검증 규칙과 함께 적용한다.

**정상 접속 + 목적 일치 + 최신성** 세 조건을 모두 만족해야 PASS다.

하나라도 실패하면 해당 링크를 교체하거나 삭제하고 본문도 함께 수정한다.

# 본문과 링크 배치

링크는 독자가 행동하려는 시점에 가깝게 배치하거나, 글 하단에 다음 섹션으로 정리한다.

## 공식 확인·신청 바로가기

### ① 신청하기
[공식 신청 페이지](https://example.com)

### ② 대상 확인하기
[공식 대상 안내](https://example.com)

### ③ 공식 발표 확인하기
[운영기관 공식 발표](https://example.com)

주제에 필요하지 않은 링크는 억지로 추가하지 않는다.

# 게시용 링크와 출력 표면

독자용 공식 링크가 필요한 글은 **일반 본문형 출력**을 기본으로 한다.

- 링크 문구 자체가 클릭 가능한가
- 사용자 화면에 실제 링크가 렌더링되는가
- 복사 전 화면에서 링크 목적을 확인할 수 있는가

글쓰기 블록은 외부 링크 보존이 확실한 경우 또는 링크가 필요 없는 글에서만 사용한다.

링크 렌더링이 실패하면:
1. 링크가 실패했다고 판단한다.
2. 링크 없는 상태를 완료로 처리하지 않는다.
3. 실제 클릭이 가능한 `[문구](URL)` 형식으로 다시 출력한다.

# 출처 목록

사용자가 출처를 요청하지 않았다면 조사 과정의 전체 출처 목록을 게시용 원고 뒤에 자동으로 붙이지 않는다.

단, **독자가 실제 신청·조회·예약·공식 원문 확인을 위해 필요한 링크는 게시용 원고에 포함한다.**

출처 요청 시 게시용 원고와 분리해:
- 기관명
- 자료명
- 공식 페이지
중심으로 제공한다.
