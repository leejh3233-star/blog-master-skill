# Knowledge — 독자용 공식 링크

게시용 원고 작성 시 **독자가 실제 행동하거나 공식 원문을 확인하는 데 필요한 링크**가 있는지 검사한다.

링크는 장식이나 출처 나열이 아니라 다음 행동을 돕기 위해 사용한다.

## 우선순위

**실제 신청·예약·조회·납부 페이지 → 직접 운영기관 안내 → 정부·공공기관·법령 원문 → 제조사·기업 공식 페이지 → 신뢰 가능한 보조자료**

우선 연결 대상:
- 신청
- 자격조회
- 예약
- 요금확인
- 납부
- 잔여석·재고조회
- 서류발급
- 법령원문
- 공식공고
- 위치·교통
- 공식사양
- 고객센터·분쟁조정·상담

가능하면 홈페이지 메인보다 **해당 행동을 바로 할 수 있는 직접 페이지**를 연결한다.

---

# 링크 문구

`여기 클릭`, `바로가기`처럼 목적이 불분명한 표현보다 다음처럼 작성한다.
- 복지로에서 신청하기
- 국가법령정보센터에서 법령 확인
- 코레일 승차권 예매
- 공식 고객센터 안내 확인

링크 문구만 보고도 무엇을 하게 되는지 이해할 수 있어야 한다.

---

# 링크 수

모든 사실에 링크를 붙이지 않는다.
같은 링크를 반복하지 않는다.
조사 출처 전체를 게시용 링크로 바꾸지 않는다.

출처와 독자용 링크를 구분한다.

- **출처:** 작성자의 검증 자료
- **독자용 링크:** 신청·조회·예약·원문 확인 등 다음 행동을 위한 페이지

링크가 없어도 본문만으로 핵심 내용을 이해할 수 있어야 한다.

---

# 삽입 전 검증

각 링크는 삽입 전에 확인한다.

1. 현재 접속 가능한가
2. 최신 연도·현재 제도인가
3. 신청 페이지와 안내 페이지를 혼동하지 않았는가
4. 지역·대상·사업이 맞는가
5. 종료된 사업이나 전년도 페이지가 아닌가
6. 홈페이지 메인보다 더 직접적인 공식 페이지가 있는가
7. 링크 문구와 실제 페이지 목적이 일치하는가

정확한 공식 페이지를 확인하지 못하면 URL을 임의로 만들지 않고 링크를 생략한다.

---

# 게시용 링크와 출력 표면

링크가 필요한 글은 최종 출력 단계에서 다음을 확인한다.

- 링크 문구 자체가 클릭 가능한가
- 사용자 화면에 실제 링크가 렌더링되는가
- 링크가 글쓰기 블록/복사 과정에서 사라지는 환경이라면 링크 포함 완료로 판정하지 않는다

**독자용 공식 링크가 필요한 글은 일반 본문형 출력이 기본이다.**

글쓰기 블록은 외부 링크 보존이 확실한 경우 또는 링크가 필요 없는 글에서만 사용한다.

링크 렌더링이 실패하면:
1. 링크가 실패했다고 명확히 판단
2. 링크 없는 상태를 완료로 처리하지 않음
3. 가능한 출력 방식 중 실제 클릭이 되는 방식을 사용

# 출처 목록

사용자가 출처를 요청하지 않았다면 별도의 출처 목록을 게시용 원고 뒤에 자동으로 붙이지 않는다.

출처 요청 시 게시용 원고와 분리해:
- 기관명
- 자료명
- 공식 페이지
중심으로 제공한다.
