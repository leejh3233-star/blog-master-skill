# Knowledge — 검색의도·SEO·글쓰기

# 1. 검색의도

검색자의 핵심 목적을 먼저 판단한다.

대표 유형:
- 정보 확인
- 대상 확인
- 신청
- 문제 해결
- 비교
- 가격
- 시기
- 구매 검토
- 여행 준비
- 사용법

검색의도는 제목·도입·소제목 구조에 반영한다.

---

# 2. 키워드 운영

내부적으로 다음을 분석한다.
- 메인 키워드
- 서브 키워드
- 연관 키워드
- 롱테일 키워드
- 실제 검색 질문

메인 키워드는 제목·도입·핵심 문단에 자연스럽게 사용한다.
나머지는 관련 문단에 분산한다.

키워드를 위해 부자연스러운 문장을 만들거나 같은 표현을 반복하지 않는다.

---

# 3. 제목 선정

여러 제목 후보를 내부 평가한다.

평가기준:
- 검색의도 일치
- 키워드 자연스러움
- 정보 명확성
- 본문과의 일치
- 과장 없음
- 클릭할 이유가 분명함

제목의 숫자·금액·기간·대상은 본문에서 정확히 설명한다.

낚시성 제목보다 검색자가 무엇을 얻는지 명확한 제목을 우선한다.

---

# 4. 문단 구조

각 소제목은 하나의 검색 질문에 답한다.

필요한 경우 문단별로 다음을 정한다.
- 독자 질문
- 핵심 답
- 팩트
- 숫자
- 예외
- 주의사항
- 예시
- 키워드
- 이미지 핵심정보

기본 흐름:
**도입 → 핵심 답 → 대상·조건 → 금액·기간 → 신청·이용방법 → 주의사항 → 활용 팁 → 마무리**

주제에 따라 순서는 변경 가능하다.

비교형:
- COMPARE
- PROSCONS
- TRADEOFF

절차형:
- STEP
- CHECK

복잡한 개념:
- EXAMPLE
- ANALOGY
- GLOSSARY

필요할 때만 사용한다.

---

# 5. 게시용 문체

도입은 짧게 구성한다.

**검색자의 상황·질문 → 핵심 답 → 글에서 확인할 내용**

피해야 할 시작:
- 안녕하세요
- 오늘은 ~ 알아보겠습니다
- 끝까지 읽어주세요

존댓말을 사용하되 지나치게 딱딱하거나 가볍지 않게 한다.

짧고 명확한 문장을 기본으로 한다.
같은 결론을 반복하지 않는다.

날짜·금액·대상·조건·주의사항은 필요하면 표·목록·짧은 문단으로 정리한다.

가상 사례는 반드시 `예를 들어`, `가정하면` 등으로 표시한다.

---

# 6. 모바일 가독성

- 한 문단은 1~3문장을 우선한다.
- 소제목은 짧고 질문 의도가 보이게 한다.
- 중요한 숫자·날짜·금액은 문장 속에 묻지 않는다.
- 지나치게 넓은 표는 피한다.
- 핵심 답을 첫 화면에서 찾을 수 있게 한다.
- 같은 의미를 여러 번 강조하지 않는다.

---

# 7. 게시용 원고 우선순위

1. 검색자의 질문에 정확히 답한다.
2. 검증된 최신 정보를 사용한다.
3. 핵심 답을 쉽게 찾게 한다.
4. 중요한 예외와 리스크를 숨기지 않는다.
5. 자연스러운 한국어로 쓴다.
6. 제목과 본문을 일치시킨다.
7. 모바일에서 읽기 쉽게 구성한다.
8. SEO 키워드를 자연스럽게 포함한다.
9. 필요한 공식 행동 링크를 제공한다.

키워드를 위한 글을 쓰지 않는다.
