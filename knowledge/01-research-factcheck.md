# Knowledge — 자료조사·팩트체크

# 1. 자료 신뢰도

## A급
- 정부·중앙부처·지자체·공공기관
- 법령 원문
- 국가통계
- 국가연구기관
- 학술지 원문
- 대학·전문의료기관
- 기업 공식 공시
- 제조사 공식 문서

## B급
- 주요 언론
- 전문매체
- 학회
- 전문 연구기관
- 협회
- 기업 공식 보도자료

## C급
- 블로그
- 카페
- 커뮤니티
- SNS
- 개인 영상
- 후기

C급은 관심사·경험·검색 표현 파악에 활용할 수 있다.
하지만 정책·지원금·세금·연금·법률·의료·날짜·금액·통계·연구결과·공식사양은 C급만으로 확정하지 않는다.

우선순위:
**공식성 → 최신성 → 원문 → 직접 운영기관 → 전문성 → 구체적 근거**

# 2. 최신성 검증

다음 변동 정보는 현재 자료를 확인한다.
- 정책
- 복지
- 세금
- 연금
- 금융
- 법률
- 부동산
- 교통
- 여행
- 행사
- 입시
- 의료제도
- 가격
- 제품사양

다음을 혼동하지 않는다.
- 게시일 / 시행일
- 발표일 / 적용일
- 신청기간 / 사용기간
- 전국 / 지역
- 확정 / 예정
- 현재 / 전년도

현재 또는 미래 정책이 공식 발표 전이면 전년도 정보를 연도만 바꿔 현재 정보처럼 작성하지 않는다.
반드시 `확정 / 예정 / 전년도 기준 / 공식 발표 전 / 전망`을 구분한다.

---

# 3. 숫자 검증

금액·비율·날짜·연령·통계·가격·지급액·소득기준 등 핵심 숫자는 재확인한다.

다음을 구분한다.
- 기준연도
- 단위
- 최대 / 평균 / 최소
- 세전 / 세후
- 개인 / 가구
- 월 / 연
- 확정 / 예상

중요한 날짜·금액·대상·조건·정책변경·통계·연구결과·건강효과·제품성능은 가능한 경우 신뢰 가능한 자료 2개 이상으로 교차검증한다.

자료가 다르면:
1. 기준시점
2. 적용연도
3. 대상
4. 지역
5. 운영기관
6. 집계방식
을 비교한다.

해결되지 않으면 임의로 하나를 선택하지 않는다.

---

# 4. 독립 2차 팩트체크

초안 후 최신 공식 자료와 다시 대조한다.

검사항목:
- 연도
- 시행일
- 신청·사용기간
- 마감시간
- 금액·단위
- 대상·연령
- 소득·자격
- 예외·제외
- 자동 적용
- 지역 차이
- 예산 소진
- 신청방법
- 최신 변경사항
- 독자용 링크

의미 왜곡 예:
- 가능 → 확정
- 최대 → 일반값
- 일부 → 전체
- 평균 → 개인값
- 예정 → 시행 중
- 권고 → 의무
- 관련성 → 인과관계
- 신청 가능 → 지급 확정

오류가 있으면 최종 원고 자체를 수정한다.

# 5. 주제별 고위험 검증

## 정부지원금·복지
대상, 금액, 기간, 자격, 지역, 예산, 예외, 자동지급 여부

## 연금
연도, 금액, 감액, 부부 여부, 소득조건

## 세금
과세연도, 신고기간, 기준, 공제, 예외

## 건강
일반 정보와 개인 진단·치료를 구분한다.
효능을 과장하지 않는다.

## 법률
일반 정보와 개인 법률자문을 구분한다.

## 제품
공식 사양과 후기·평가를 구분한다.

## 여행·시설
운영시간, 휴무, 요금, 예약, 공사, 계절성을 확인한다.

## 경제·금융
확정 발표와 전망을 구분하고 주요 위험을 함께 확인한다.
