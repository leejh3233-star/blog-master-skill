# Knowledge — REAL IMAGE MODE

방송·연예·실존 인물·실제 장소·행사·제품처럼 **실제 모습과 정체성이 중요한 주제**에서는 100% AI 생성 이미지만 고집하지 않는다.

목표는 **사실성과 몰입도를 높이되, 저작권·초상권·출처 문제를 피하면서 실제 이미지 자산을 가장 안전하게 활용하는 것**이다.

## 1. REAL IMAGE MODE 발동 조건

다음 주제에서는 자동으로 검토한다.
- 연예인·방송인·가수·배우·스포츠 선수 등 실존 인물
- TV 프로그램·유튜브 방송·공식 행사
- 실제 음식점·여행지·시설·공연장·지역 명소
- 실제 제품·자동차·전자기기
- 사용자가 특정 사진·포스터·방송 화면을 기준으로 작업하길 원하는 경우

## 2. 이미지 조사 우선순위

실제 이미지를 찾을 때는 다음 순서를 우선한다.

1. 방송사·제작사·소속사·공공기관·브랜드 공식 페이지
2. 공식 보도자료·프레스킷·미디어센터
3. 공식 SNS·공식 유튜브·공식 행사 페이지
4. 사용 조건이 명확한 공공·오픈 라이선스 이미지
5. 주요 언론·전문매체의 보도 이미지 — 사실 확인·시각 참고용
6. 일반 블로그·커뮤니티·SNS — 보조 참고만

인물의 얼굴, 의상, 프로그램명, 장소 외관 등 **정체성 확인은 여러 공식 이미지로 교차 확인**한다.

## 3. IMAGE SOURCE LEDGER

실제 이미지가 필요한 경우 내부적으로 다음을 기록한다.
- 이미지 대상
- 출처 사이트/기관
- 공식 여부
- 원본 페이지
- 촬영/게시 시점
- 사용권·라이선스 표시 여부
- 실제 재사용 가능 여부
- 사실 확인용 참고만 가능한지
- 이미지 생성 시 참고할 시각 요소

사용권이 불명확하면 `REFERENCE_ONLY`로 처리한다.

## 4. 실제 이미지 활용 방식

### A. 직접 사용 가능
다음 조건을 확인할 수 있는 경우 실제 이미지 활용 후보로 본다.
- 공식 프레스 이미지이며 이용 조건이 명확함
- 공공누리·CC 등 허용 범위가 명확함
- 사용자 본인이 제공했거나 사용 권한을 가진 이미지

이 경우에도 출처표시 조건이나 수정 제한이 있으면 그대로 따른다.

### B. 참고만 가능
저작권 상태가 불명확한 방송 캡처·언론 사진·SNS 사진은 **그대로 재배포하거나 무단 재가공하는 것을 기본값으로 하지 않는다.**

대신:
- 인물·장소·의상·배경의 사실 확인
- 방송 장면의 맥락 확인
- 색감·구도·분위기 참고
용도로만 사용한다.

그 후 원본과 다른 **새로운 편집적 비주얼**을 생성한다.

## 5. 웹에서 찾은 이미지를 재가공할 때의 제한

웹에서 검색으로 찾은 이미지를 곧바로 이미지 편집 도구에 넣어 원본을 변형했다고 가정하지 않는다.

실제 재가공이 필요하면:
- 사용자가 현재 대화에 이미지를 업로드했거나
- 사용 권한이 명확한 원본이 작업 입력으로 제공되어야 한다.

웹에서 찾은 이미지는 기본적으로 **시각 참고자료**로 사용한다.

## 6. 실존 인물 이미지 제작

연예인 등 실존 인물이 핵심인 글에서는 이름만 넣은 일반 AI 인물로 대체하지 않는다.

먼저 공식 이미지 여러 장으로 다음을 확인한다.
- 얼굴 특징
- 헤어스타일
- 대표적인 최근 이미지
- 방송/행사 당시 의상이나 분위기
- 프로그램/장소 맥락

그 뒤 원본 사진 한 장을 그대로 복제하지 않는 **새로운 장면·구도·정보 카드**를 설계한다.

사용자가 실제 사진을 업로드해 재가공을 요청하면 그 이미지를 기준으로 편집한다.

## 7. 방송·연예 콘텐츠용 이미지 구성 예

- 대표 이미지: 인물 + 프로그램/이슈 핵심 제목
- 본문 이미지 2: 방송 장면 맥락 또는 인물 중심
- 본문 이미지 3: 장소·식당·여행지 실제 외관 또는 그에 가까운 사실 기반 비주얼
- 본문 이미지 4: 일정·가격·위치·핵심 정보 카드

모든 이미지를 같은 인물 사진 중심으로 반복하지 않는다.

## 8. 실제 이미지와 AI 이미지 혼합 원칙

한 글의 이미지 세트는 필요에 따라 다음을 혼합할 수 있다.
- 실제 사용 가능한 공식 이미지
- 실제 장소/제품의 공식 이미지
- AI 생성 정보 카드
- AI 생성 보조 장면
- 지도·일정·가격·절차 그래픽

목표는 `100% AI`가 아니라 **정보 신뢰도 + 시각 몰입도 + 권리 안전성**의 균형이다.

## 9. 금지

- 출처·권리 불명확한 사진을 다운로드해 그대로 재가공했다고 표시
- 방송 화면·연예인 사진을 무단 사용 가능하다고 단정
- 실제 인물·장소와 다른 외형을 사실처럼 제시
- 존재하지 않는 방송 장면을 실제 캡처처럼 표현
- 가짜 방송사·브랜드 로고 삽입
- 원본 사진 한 장을 사실상 복제하는 구도·표정·배경 재현
- 사용권 확인 없이 `사용 가능`으로 판정

## 10. 최종 판단

실제성이 중요한 주제에서는 다음 순서로 결정한다.

1. 공식·허용 이미지가 있는가?
2. 직접 사용 가능 여부가 명확한가?
3. 아니면 사실 확인용 참고자료로만 사용할 것인가?
4. AI 생성이 더 안전하고 유용한 부분은 무엇인가?
5. 이미지 간 역할이 겹치지 않는가?
6. FINAL_ARTICLE 밖의 새로운 사실을 만들고 있지 않은가?

**실제 이미지를 찾을 수 있다는 이유만으로 무조건 재사용하지 않는다.**
**AI로 만들 수 있다는 이유만으로 실제 자료조사를 생략하지 않는다.**
