# NAVER Blog Master Skill v3.8

네이버 블로그 글쓰기·운영을 위한 **AI 멀티에이전트 편집국 Skill**입니다.

사용자는 키워드 하나, 큰 주제 하나, 목적 한 줄, 또는 정리되지 않은 설명만 던져도 됩니다.

```text
$naver-blog-master AUTO FULL
지금 조회수를 최대한 노릴 수 있는 주제를 찾아서 글을 완성해줘.
```

## v3.8 핵심 변화

v3.8은 **링크가 내부적으로 검증된 것과 사용자 화면에서 실제로 보이는 것을 분리해서 검수**합니다.

이전에는 링크가 정상 URL이어도 ChatGPT 글쓰기 블록 안에서 링크 표현이 사라지거나 복사되지 않을 수 있었습니다.
이제는 이런 경우를 PASS 처리하지 않습니다.

기본 링크 흐름:

```text
링크 후보 검색
↓
PASS 1 — 실제 오픈 검증
↓
목적·공식도메인·현재성 확인
↓
PASS 2 — 전달 직전 재검증
↓
링크 전달 방식 결정
↓
USER-VISIBLE LINK GATE
↓
필요 시 COPYABLE EXPORT
↓
PRE-PUBLISH RECHECK
↓
FINAL PASS
```

## LINK DELIVERY MODE

### 1) INLINE_VISIBLE
현재 출력 화면에서 글쓰기 블록 안 링크가 실제로 보이고 클릭 가능하게 유지되는 경우.

### 2) MARKER_PLUS_PANEL
현재 ChatGPT처럼 글쓰기 블록 안 링크 렌더링이 불안정한 경우의 기본 안전 방식입니다.

본문에는:

```text
[공식 링크 L1 — 근로장려금 신청 바로가기]
```

처럼 위치 마커를 넣고, 글 바로 아래에 같은 번호의 실제 클릭 가능한 링크 패널을 제공합니다.

마커만 있고 클릭 패널이 없으면 FAIL입니다.

### 3) COPYABLE_EXPORT
네이버 편집기에 그대로 복사하면서 실제 URL 문자열까지 보존해야 하는 경우, 가능한 환경에서는 링크 포함 `TXT` 또는 `HTML` 발행본을 별도로 만듭니다.

LINK-CRITICAL 글에서 글쓰기 블록 링크 보존이 확실하지 않다면 이 방식을 우선 사용합니다.

## LINK-CRITICAL MODE

다음처럼 링크가 핵심인 글은 자동 적용합니다.

- 예매
- 신청
- 가입
- 예약
- 지도/길찾기
- 잔여석/재고
- 지원금/정책 신청
- 통신사·쇼핑 공식 신청
- 방송 공식 클립
- 독자가 직접 공식자료로 팩트체크해야 하는 글

필수 링크 하나라도 검증 또는 전달에 실패하면 최종 승인하지 않습니다.

## 링크 검증 기준

- 실제로 열리는가
- 404/오류/종료 페이지가 아닌가
- 공식 도메인인가
- 링크 라벨과 실제 페이지 목적이 같은가
- 현재 연도·시즌·행사·상품과 맞는가
- 오래된 프로모션이 아닌가
- 로그인/앱 전용 제한이 있는가
- 더 직접적인 공식 deep link가 있는가
- 발행 직전에도 유효한가

## USER-VISIBLE LINK GATE

다음이 모두 맞아야 합니다.

- 사용자 화면에 링크 목적이 보임
- 실제 클릭 가능한 링크가 있음
- 본문 마커와 클릭 패널 번호가 1:1 일치
- 필수 링크가 전부 전달됨
- 내부 참조 토큰이 있다는 이유만으로 PASS하지 않음

## COPYABLE LINK GATE

사용자가 `복사 붙여넣기`, `바로 발행`, `링크까지 포함`을 원할 때 현재 화면이 URL 보존을 확실히 하지 못하면 링크 포함 복사용 export를 생성합니다.

파일 생성이 불가능한 환경이면 `COPYABLE_URL_DELIVERY = LIMITED`라고 명확히 표시하고 완전 자동 발행본이라고 주장하지 않습니다.

## 글과 이미지는 분리

```text
글 조사·검수
↓
링크 검증·전달 검수
↓
Final Control Tower 승인
↓
발행용 글쓰기 블록 + 클릭 링크 패널 + 필요 시 복사용 export + 이미지 계획 + QA
↓
PUBLISH_PACKAGE_DELIVERED = TRUE
↓
다음 사용자 턴에서 이미지 시작
```

같은 턴에서 이미지 생성 도구를 호출해 글이 사라지게 하지 않습니다.

## 최종 출력 계약

AUTO FULL의 첫 최종 응답에는 기본적으로 다음이 있어야 합니다.

1. 최종 선정 결과
2. 발행용 글쓰기 블록
3. 실제 클릭 가능한 LINK PANEL
4. 필요 시 COPYABLE PUBLISH EXPORT
5. 검증 링크팩
6. 이미지 제작팩
7. 요구사항 충족 요약 + 최종 QA
8. 이미지 큐 상태 — READY

## 체류와 수익화

체류는 반복이 아니라 새로운 가치로 만듭니다.

- 비교
- 예외
- 실수 방지
- FAQ
- 체크리스트
- 공식 영상
- 실제 내부글
- 정보가 겹치지 않는 이미지

애드포스트 광고 클릭은 직접 유도하지 않습니다.
검색 유입·정독·스크롤·내부 이동·재방문·신뢰를 높이는 방향으로 운영합니다.
