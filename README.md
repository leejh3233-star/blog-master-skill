# NAVER Blog Master Skill v3.2

네이버 블로그 글쓰기·운영을 위한 **AI 멀티에이전트 편집국 Skill**입니다.

사용자는 프롬프트를 잘 쓸 필요가 없습니다.
키워드 하나, 큰 주제 하나, 목적 한 줄, 또는 정리되지 않은 설명만 던져도 됩니다.

예:

```text
$naver-blog-master 양산 물금 중국집
```

```text
$naver-blog-master
주말에 6살 아이와 갈 만한 곳을 찾는 부모들이
도움받을 수 있는 여행글을 하나 써줘.
맛집도 같이 연결됐으면 좋겠어.
```

```text
$naver-blog-master
주제 상관없이 조회수를 최대한 높이고 싶어.
지금 검색수요가 좋은 소재를 찾아서 써줘.
```

```text
$naver-blog-master
빠르게 답을 주면서도 정독할 가치가 있고,
애드포스트 운영에도 도움이 되는 글을 써줘.
```

## v3.2 핵심 철학

**빠른 답변과 체류시간은 서로 반대가 아닙니다.**

독자가 첫 화면에서 핵심을 바로 이해한 뒤,
비교·예외·체크리스트·영상·FAQ·실수 방지·관련글 등
실제 추가 가치 때문에 자연스럽게 더 읽도록 설계합니다.

핵심 원칙:

> 답은 먼저 준다.
> 필요한 링크는 본문 안에 바로 넣는다.
> 체류시간은 반복이 아니라 추가 가치로 만든다.
> 독자를 다시 검색창으로 보내지 않는다.
> 광고 클릭은 절대 유도하지 않는다.

## 빠른 답 + 체류 구조

기본 정보성 글은 다음 3개 층으로 설계합니다.

### Layer 1 — 10초 핵심
- 한 줄 결론
- 가장 중요한 날짜/가격/조건
- 필요한 바로가기 링크

### Layer 2 — 30초 실전
- 지금 해야 할 일
- 비교 선택지
- 주의사항
- 실수 방지

### Layer 3 — 정독 가치
- 상황별 비교
- FAQ
- 체크리스트
- 계산 예시
- 실제 동선
- 영상
- 저장용 요약
- 관련 내부글

결론을 일부러 늦추거나 같은 말을 반복해서 체류를 늘리지 않습니다.

## 행동 링크는 필수

예매·예약·신청·조회·방문형 글은 필수 링크가 없으면 최종 승인하지 않습니다.

예:

```text
▶ 2026 추석 KTX 잔여석 바로 확인
▶ 매진열차 예약대기 신청
▶ 황산공원 네이버지도 보기
▶ 지원금 공식 신청 페이지
```

링크는 별도 참고 목록만 제공하는 것이 아니라 **최종 발행 본문 안의 필요한 위치에 직접 들어갑니다.**

## 주제별 링크 예시

- 맛집: 지도 / 예약 / 메뉴 / 주차
- 여행: 지도 / 공식 관광정보 / 예매 / 주차 / 교통 / 영상
- 기차: 잔여석 / 공식 예매 / 예약대기
- 정책: 공식 신청 / 자격조회 / 공고
- 스포츠: 일정 / 기록 / 중계 / 공식 하이라이트
- 방송: 공식 방송페이지 / 클립 / 장소 지도

## 체류시간과 수익화

체류시간을 검색 순위의 공식 단일 지표라고 단정하지 않습니다.
대신 다음을 운영 목표로 둡니다.

- 첫 화면 이탈 감소
- 실제 정독 가치 증가
- 저장/재방문 가치 증가
- 내부 관련글 이동
- 콘텐츠 클러스터 강화
- 모바일 읽기 편의
- 신뢰도 높은 최신 정보 제공

애드포스트 수익을 위해 광고 클릭을 직접 유도하지 않습니다.
광고 클릭 유도 문구, 화살표, 이미지, 반복 클릭 요청 등은 금지합니다.
수익은 콘텐츠 품질과 정상적인 방문자 관심이 높아지는 방향으로 접근합니다.

## 최종 출력

기본 AUTO FULL 결과:

1. 최종 선정 결과
2. **발행용 글쓰기 블록**
3. 이미지 제작팩
4. 검증된 행동 링크팩
5. 최종 QA 요약

실제로 복사할 것은 2번 글쓰기 블록 하나면 됩니다.
본문 안에 필요한 지도·예약·예매·신청·영상 링크가 이미 들어가야 합니다.
