# NAVER Blog Master Skill v2.0

네이버 블로그 글쓰기·운영을 위한 **멀티에이전트 AI Skill** 프로젝트입니다.

사용자는 큰 주제만 정하면 됩니다.

예:

```text
$naver-blog-master 여행 맛집
```

그러면 내부적으로 다음 조직이 자동으로 움직입니다.

```text
총괄팀장
→ 1단계 주제·트래픽 직원
→ 검증 직원
→ 승인 직원
→ 2단계 키워드·제목 직원
→ 검증·승인
→ 3단계 팩트·링크 직원
→ 검증·승인
→ 4단계 구조 직원
→ 검증·승인
→ 5단계 작성 직원
→ 검증·승인
→ 6단계 이미지 직원
→ 검증·승인
→ 최종 QA 팀장
→ 최종 편집장
→ 사용자에게 결과만 전달
```

## 핵심 기능

- 큰 주제만 입력하면 AUTO FULL MODE 실행
- PROJECT DNA 자동 생성·유지
- Command 400 기반 필요한 명령 자동 선택
- 네이버 실제 검색수요 기반 주제 발굴
- 검색량/경쟁도/계절성/시의성 검토
- 검색 + 홈피드 하이브리드 제목 설계
- 공식자료 우선 팩트체크
- 링크/날짜/숫자/상호/영업정보 검증
- 각 단계별 Reviewer + Approval Gate
- 미통과 결과 자동 반려·수정
- 발행용 최종 원고만 사용자에게 제공
- 실제 발행 글 기반 내부링크
- 중복 없는 개별 이미지 설계
- 최종 QA + 최종 편집장 승인
- 성과 피드백 루프

## 기본 사용법

가장 간단한 사용법:

```text
$naver-blog-master 여행 맛집
```

또는:

```text
$naver-blog-master 경주 가을 여행 맛집
```

기본값은 **AUTO FULL MODE**입니다.

AI가 내부적으로 1~6단계와 검증·승인을 모두 수행한 뒤 다음 결과만 보여줍니다.

1. 최종 선정 주제
2. 최종 제목
3. 발행용 완성 원고
4. 검증된 핵심 링크
5. 내부링크 제안
6. 이미지 삽입 위치
7. 개별 이미지 계획/프롬프트
8. 최종 검수 요약

## 권장 사용 방식

이 스킬은 특정 블로거의 문체를 복제하는 도구가 아닙니다.
상위 블로그에서 반복되는 운영 패턴, 네이버 검색수요, 공식자료, PROJECT DNA를 바탕으로 콘텐츠를 설계합니다.

실무 운영 원칙:

- 핫해 보인다는 이유만으로 주제를 선정하지 않음
- 가능하면 네이버 실제 검색수요 확인
- 타 플랫폼 검색량을 네이버 검색량으로 오인하지 않음
- 검증되지 않은 링크/숫자를 생성하지 않음
- 각 단계 결과를 Reviewer가 반박하고 Approval Manager가 승인
- 최종 QA를 통과한 결과만 사용자에게 제공
