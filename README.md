# NAVER Blog Master Skill v3.1

네이버 블로그 글쓰기·운영을 위한 **AI 멀티에이전트 편집국 Skill**입니다.

사용자는 프롬프트를 잘 쓸 필요가 없습니다.
키워드 하나, 큰 주제 하나, 목적 한 줄, 또는 정리되지 않은 설명만 던져도 됩니다.

예:

```text
$naver-blog-master 양산 물금 중국집
```

```text
$naver-blog-master
주말에 6살 아이와 갈 만한 곳을 찾는 부모들이
도움받을 수 있는 여행글을 하나 써줘.
맛집도 같이 연결됐으면 좋겠어.
```

```text
$naver-blog-master
이번에는 조회수가 목표야.
여행 맛집에서 네이버 검색수요 좋은 소재를 찾아 글을 써줘.
```

## v3.1 핵심 변화

- 자유 입력 해석
- AUTO FULL MODE에서도 1~6단계 강제 실행
- 단계별 Reviewer + Approval Gate
- 네이버 검색수요·시의성·경쟁도 검토
- Place Identity / Freshness TTL / Source Provenance
- 네이버 지도·예약·예매·공식페이지 등 Reader Action Link 검증
- YouTube 공식·전문·현장 영상 적극 활용 및 실제 내용 검증
- 모바일 퍼스트 구조
- FIRST SCREEN GATE
- Reader Search Again Score
- Reader Link / Evidence Link 분리
- 방송·스포츠·연예·실시간 이슈 Visual Fact Sheet / Rights Gate
- 이미지 문구·정보·구도 중복 검수
- 4인 Reader Simulation
- COPY CLEAN EDITOR
- 최종 발행 원고를 가능한 경우 **하나의 문서형 글쓰기 블록**으로 제공
- 이미지 제작팩·링크팩·QA 결과를 발행 원고와 분리

```text
사용자 자유 입력

↓
2단계 키워드·제목 → 검증 → 승인
↓
3단계 팩트·장소·링크·YouTube → 검증 → 승인
```

## 최종 출력 구조

AUTO FULL MODE의 기본 결과는 다음 순서입니다.

1. 최종 선정 결과
2. **발행용 글쓰기 블록**
3. 6단계 이미지 제작팩
4. 검증된 행동 링크팩
5. 최종 QA 요약

### 발행용 글쓰기 블록

호스트가 writing block을 지원하면 최종 글 전체를 **하나의 document writing block**으로 제공합니다.

글쓰기 블록에는 실제 발행할 내용만 들어갑니다.

- 최종 제목
- 도입부
- 본문
- 독자 행동 링크
- `[이미지 N — 설명]` 삽입 표시
- 마무리
- 태그

다음 내용은 글쓰기 블록에 넣지 않습니다.

- 내부 tool/ref/citation 코드
- 에이전트명
- Command 목록
- 조사 로그
- 검수 회의 내용
- 테스트 문장

사용자는 기본적으로 **글쓰기 블록 하나만 복사해 네이버에 붙여넣으면 됩니다.**

## 모바일 퍼스트

최종 글은 PC보다 스마트폰 화면을 우선합니다.

- 짧은 문단
- 짧고 명확한 소제목
- 긴 표보다 세로 카드형 요약
- 중요 숫자·시간·가격을 문장 속에 숨기지 않음
- 링크는 필요한 문단 바로 아래
- 첫 5~8줄 안에 글의 가치 제시
- 이미지로 긴 글의 호흡을 자연스럽게 분리

## 링크 정책

### Reader Link
독자가 실제 행동할 때 필요한 링크:
- 네이버 지도
- 예약
- 예매
- 운영시간
- 공식 관광정보
- 교통
- YouTube

→ 본문에 적극 배치합니다.

### Evidence Link
팩트 검증에 필요한 링크:
- 통계
- 보도자료
- 공식 공고
- 연구자료

→ 독자에게 실제 도움이 될 때만 본문에 노출합니다.

링크는 접속 가능 여부와 목적 페이지를 확인하고, 가능한 경우 추적 파라미터를 제거한 canonical URL을 사용합니다.

## 이미지 정책

이미지는 개별 업로드용으로 설계합니다.
각 이미지마다 역할이 달라야 합니다.

검수 항목:
- 문구 중복
- 정보/의미 중복
- 구도 중복
- 본문과의 사실 일치
- 모바일 가독성

방송·스포츠·연예·실시간 이슈는 Visual Fact Sheet와 Rights Gate를 통과한 뒤 설계합니다.

## 전문가 모드

특정 단계만 보고 싶다면:

```text
1단계만
2단계만
3단계만
4단계만
5단계만
6단계만
```

검수만 보고 싶다면:

```text
검수
내부 보고서
왜 이 주제를 골랐어?
```

공유 가능한 검증 데이터와 판단 요약만 보여주며 비공개 사고과정 전체는 출력하지 않습니다.
