# NAVER Blog Master Skill v4.0

네이버 블로그 글쓰기·운영을 위한 **AI 멀티에이전트 편집국 Skill**입니다.

```text
$naver-blog-master AUTO FULL
지금 조회수를 최대한 노릴 수 있는 주제를 찾아서 글을 완성해줘.
```

## v4.0 핵심 변화

v4.0은 **최종 발행 원고의 출력 형식만 변경**합니다.

이전의 writing block 방식 대신, 이제 최종 발행 원고는 **일반 채팅 본문형**으로 제공합니다.

중요한 점은 글 품질 시스템은 그대로 유지된다는 것입니다.

유지되는 핵심:
- No-Skip Micro-Gate Pipeline
- Requirement Ledger
- 트래픽·주제 선정
- 검색의도·키워드·제목 설계
- 공식자료 우선 팩트체크
- 교차검증
- 링크 필요성 정의
- 링크 실제 오픈 검증
- 본문 클릭 링크 삽입
- 삽입 링크 재검증
- 발행 직전 링크 재확인
- Answer First
- Retention Architecture
- No-Search-Back
- Mobile First
- 내부링크 실재 확인
- 이미지 권리·사실 검수
- Final Control Tower

즉:

> 출력 형식만 일반 본문형으로 바꾸고, 품질·팩트체크·검증 강도는 낮추지 않습니다.

## 최종 발행 원고 형식

기본은 이런 형태입니다.

```text
# 제목

핵심답과 도입

## 소제목
본문

공식 신청 바로가기 ← 이 문구 자체에 클릭 링크

[이미지 1 삽입 — 역할]

...

#태그
```

writing block은 기본 최종 발행 형식으로 사용하지 않습니다.
사용자가 명시적으로 요청한 경우에만 예외적으로 사용합니다.

## 전체 Micro-Gate 흐름

```text
STAGE 0 입력·요구사항 잠금
↓
STAGE 1 조회수·주제 선정
↓
STAGE 2 키워드·제목·첫 화면
↓
STAGE 3A 팩트 조사
↓
STAGE 3B 필요한 링크 목록 정의
↓
STAGE 3C 링크 후보 검색
↓
STAGE 3D 링크 실제 오픈 검증
↓
STAGE 3E 링크 위치 결정
↓
STAGE 4 글 구조·체류 설계
↓
STAGE 5A 본문 작성
↓
STAGE 5B 일반 본문 안 클릭 가능한 문구 링크 삽입
↓
STAGE 5C 삽입 링크 재검증
↓
STAGE 5D 2차 팩트체크
↓
STAGE 5E 일반 본문 전달 검수
↓
STAGE 6 이미지 계획·권리·사실 검수
↓
FINAL GATES
↓
Final Control Tower
```

각 단계는 반드시:

```text
작업 → 독립 검수 → 승인
```

을 통과합니다.

PASS가 아니면 다음 단계로 넘어가지 않습니다.

## 팩트체크 원칙

출처 우선순위:
1. 정부·공공기관·공식 홈페이지·공식 통계·공식 방송
2. 주요 언론·전문기관·연구기관
3. 블로그·SNS·커뮤니티

중요 숫자는 가능하면 공식자료 또는 복수의 신뢰 출처로 확인합니다.

확인 항목:
- 날짜
- 가격
- 신청기간
- 영업시간
- 주소·지점
- 이전·폐업·상호변경
- 행사 일정
- 방송 정보
- 공식 영상
- 링크

확인되지 않은 검색량·가격·시간·주소·URL을 만들지 않습니다.

## 링크 검증

링크는 한 번 찾고 끝내지 않습니다.

1. 필요한 링크 종류 먼저 정의
2. 공식 deep link 검색
3. 실제 오픈
4. 공식 도메인·목적·현재성 확인
5. 본문 위치 결정
6. 일반 본문 안 클릭 가능한 문구 링크 삽입
7. 삽입된 링크 다시 검증
8. 날짜 민감 링크는 발행 직전 재확인

LINK-CRITICAL 주제에서는 링크 단계 생략이 금지됩니다.

대상 예:
- 예매
- 신청
- 가입
- 예약
- 지도·길찾기
- 잔여석·재고
- 정책·지원금
- 통신사·쇼핑 신청
- 공식 방송·클립

## 링크 위치

기본 원칙:

> 답은 초반에, 깊이는 중간에, 행동 링크는 후반에.

- URGENT: 상단 10~25%
- STANDARD: 후반 60~90%
- FACT-CHECK: 관련 설명 뒤 또는 후반
- INTERNAL: 실제 발행글만 중반 이후

## 모바일·체류

모바일 우선:
- 1~3문장 문단
- 짧은 소제목
- 핵심 숫자 분리
- 넓은 표보다 세로 정보
- 첫 화면 핵심답

체류는 반복이 아니라 추가가치로 만듭니다.
- 비교
- 예외
- 실수 방지
- FAQ
- 체크리스트
- 영상
- 정보 이미지
- 실제 내부글
- 다음 행동

## 이미지

글이 먼저 완성된 뒤 다음 메시지로:

```text
이미지 시작
```

또는 `1`을 입력합니다.

그다음은 `다음`만 입력하면 됩니다.

이미지는 한 장씩 개별 생성하고, 실제 인물·방송·장소는 사실성과 권리를 검증합니다.

## 최종 출력 계약

AUTO FULL 정상 결과:

1. 최종 주제·제목·키워드
2. **일반 본문형 최종 발행 원고**
3. 검증 링크팩
4. 이미지 제작팩
5. Requirement Ledger 요약
6. Final QA
7. 이미지 큐 READY

2번이 실제 복사·발행용 핵심 원고입니다.
