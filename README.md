# NAVER Blog Master Skill v3.7

네이버 블로그 글쓰기·운영을 위한 **AI 멀티에이전트 편집국 Skill**입니다.

사용자는 키워드 하나, 큰 주제 하나, 목적 한 줄, 또는 정리되지 않은 설명만 던져도 됩니다.

예:

```text
$naver-blog-master AUTO FULL
지금 조회수를 최대한 노릴 수 있는 주제를 찾아서 글을 완성해줘.
```

## v3.7 핵심 변화

v3.7은 **링크가 실제로 작동하는지 여러 번 검증하는 버전**입니다.

이전에는 링크가 본문에 들어갔는지까지 확인했다면, 이제는 그 링크가 실제로 열리고 목적 페이지와 맞는지까지 확인합니다.

기본 흐름:

```text
링크 후보 검색
↓
PASS 1 — 후보 URL 실제 오픈 검증
↓
본문에 raw canonical URL 삽입
↓
PASS 2 — 본문에 들어간 정확한 URL 다시 오픈
↓
PRE-PUBLISH RECHECK — 발행 직전 다시 확인
↓
FINAL PASS
```

## LINK-CRITICAL MODE

다음처럼 링크가 글의 핵심인 주제는 자동으로 `LINK_CRITICAL_MODE`가 켜집니다.

- 예매
- 신청
- 가입
- 예약
- 지도/길찾기
- 잔여석/재고
- 정책/지원금 신청
- 통신사·쇼핑 공식 신청 페이지
- 공식 방송/클립
- 직접 팩트체크가 중요한 글

이 모드에서는 필수 링크 하나라도 최종 검증을 통과하지 못하면 글 전체를 승인하지 않습니다.

## 링크 검증 기준

각 필수 링크는 최소한 다음을 확인합니다.

- 실제로 열리는가
- 404/오류/종료 페이지가 아닌가
- 최종 도착 도메인이 공식 도메인인가
- 링크 라벨과 실제 페이지 목적이 일치하는가
- 현재 연도·시즌·행사·제품과 맞는가
- 오래된 프로모션이나 종료 이벤트가 아닌가
- 불필요한 추적 파라미터를 제거해도 정상 동작하는가
- 더 직접적인 공식 deep link가 있는가
- 로그인/앱 전용 등의 제약이 있는가

## 본문 링크도 다시 검증합니다

글쓰기 블록에 링크를 넣은 뒤, **블록에서 실제로 보이는 URL 문자열을 다시 복사해 재오픈**합니다.

따라서 다음 오류를 막습니다.

- URL 잘림
- 오타
- 잘못된 canonical 정리
- 라벨과 실제 URL 불일치
- 이전 시즌 페이지 연결

## 본문 링크 형식

네이버 복사·붙여넣기를 고려해 Markdown 링크에만 의존하지 않습니다.

```text
▶ Apple 공식 사전예약 확인
https://www.apple.com/...
```

처럼 **목적 문구 + 다음 줄 raw URL**을 기본으로 합니다.

블록 밖 링크팩은 관리용 사본일 뿐이며 본문 링크를 대신할 수 없습니다.

## 링크 위치 원칙

기본:

> 답은 초반에, 깊이는 중간에, 행동 링크는 후반에.

- `URGENT` — 오늘 마감·잔여석 등: 상단 10~25%
- `STANDARD` — 지도·예약·가입·신청·일반예매: 후반 60~90%
- `FACT-CHECK` — 공식자료·통계·보도자료: 관련 설명 뒤 또는 후반
- `INTERNAL` — 실제 발행한 관련글만 중반 이후

필수 링크를 빼서 체류를 강제하지 않고, 너무 일찍 외부로 내보내지도 않습니다.

## 최종 출력 계약

AUTO FULL의 첫 최종 응답에는 반드시 다음 7개가 있어야 합니다.

1. 최종 선정 결과
2. 실제 URL이 포함된 발행용 글쓰기 블록
3. 검증 링크팩
4. 이미지 제작팩
5. 요구사항 충족 요약
6. 최종 QA
7. 이미지 큐 상태 — `READY`

검증 링크팩에는 각 링크의 PASS 1 / 본문 삽입 / PASS 2 / 발행 직전 재확인 상태를 포함합니다.

## 글과 이미지는 분리

```text
글 조사·검수
↓
Final Control Tower 승인
↓
발행용 글쓰기 블록 + 검증 링크 + 이미지 계획 + QA
↓
PUBLISH_PACKAGE_DELIVERED = TRUE
↓
다음 사용자 턴에서 이미지 시작
```

같은 턴에서 이미지 생성 도구를 호출해 글이 사라지게 하지 않습니다.

## 체류와 수익화

체류는 반복이 아니라 추가 가치로 만듭니다.

- 비교
- 예외
- 실수 방지
- FAQ
- 체크리스트
- 공식 영상
- 실제 내부글
- 정보가 겹치지 않는 이미지

애드포스트 광고 클릭은 직접 유도하지 않습니다.
검색 유입·정독·스크롤·내부 이동·재방문·신뢰를 높이는 방향으로 운영합니다.

## 이미지 큐 사용법

글이 먼저 완성된 뒤:

```text
이미지 큐: READY
NEXT_IMAGE_INDEX: 1
```

상태가 나오면 다음 메시지로 `이미지 시작` 또는 `1`을 입력합니다.
그다음은 `다음`만 입력하면 됩니다.
