# NAVER Blog Master Skill v3.6

네이버 블로그 글쓰기·운영을 위한 **AI 멀티에이전트 편집국 Skill**입니다.

사용자는 키워드 하나, 큰 주제 하나, 목적 한 줄, 또는 정리되지 않은 설명만 던져도 됩니다.

예:

```text
$naver-blog-master AUTO FULL
지금 조회수를 최대한 노릴 수 있는 주제를 찾아서 글을 완성해줘.
```

## v3.6 핵심 변화

v3.6은 **발행용 글쓰기 블록 안의 실제 링크 누락을 막는 버전**입니다.

이전에는 링크 검증과 링크팩이 정상이어도, 최종 글쓰기 블록에는 `공식 페이지에서 확인하세요` 같은 문장만 남고 실제 URL이 빠질 수 있었습니다.

이제는:

```text
링크 조사·검증
↓
READER_REQUIRED 링크 선정
↓
본문 삽입 위치 결정
↓
발행용 글쓰기 블록 안에 실제 canonical URL 삽입
↓
Inline Link Auditor
↓
EXPECTED_READER_LINK_COUNT == INLINE_READER_LINK_COUNT 확인
↓
PASS일 때만 최종 승인
```

순서로 동작합니다.

## 링크는 반드시 글 안에도 들어갑니다

링크팩은 관리용 사본일 뿐입니다.

**링크팩에 URL이 있어도 글쓰기 블록 안에 실제 URL이 없으면 FAIL**입니다.

기본 표기 형식:

```text
▶ Apple 공식 사전예약 확인
https://www.apple.com/...
```

처럼 **링크 목적 + 다음 줄 실제 URL**을 사용합니다.

Markdown 링크 문법에만 의존하지 않기 때문에 네이버 편집기로 복사할 때도 주소가 사라지는 문제를 줄입니다.

## 링크 종류별 기본 위치

- `URGENT` — 오늘 마감·잔여석 등: 상단 10~25%
- `STANDARD` — 지도·예약·가입·신청·일반예매: 후반 60~90%
- `FACT-CHECK` — 공식자료·통계·보도자료: 관련 설명 뒤 또는 후반
- `INTERNAL` — 실제 발행한 관련글만 중반 이후

즉:

> 답은 초반에, 깊이는 중간에, 실제 행동 링크는 적절한 후반에.

## 링크 누락 방지 규칙

v3.6은 다음을 FAIL 처리합니다.

- `공식 링크에서 확인하세요`라고 쓰고 URL이 없음
- 링크팩만 있고 본문에는 링크가 없음
- 링크 라벨만 있고 복사 가능한 실제 URL이 없음
- 잘못된 홈페이지 메인 주소로 대체
- 검증되지 않은 URL 추측
- 같은 URL을 반복해 링크 개수만 맞춤

## 글과 이미지는 계속 분리됩니다

v3.5부터 적용된 Delivery Barrier는 그대로 유지합니다.

```text
글 조사·검수
↓
Final Control Tower 승인
↓
발행용 글쓰기 블록 + 본문 실제 링크 + 링크팩 + 이미지 계획 + QA
↓
PUBLISH_PACKAGE_DELIVERED = TRUE
↓
다음 사용자 턴에서 이미지 시작
```

같은 턴에서 이미지 생성 도구를 호출해 글이 사라지게 하지 않습니다.

## 최종 출력 계약

AUTO FULL의 첫 최종 응답에는 반드시 다음 7개가 있어야 합니다.

1. 최종 선정 결과
2. **실제 URL이 들어간 발행용 글쓰기 블록**
3. 검증 링크팩
4. 이미지 제작팩
5. 요구사항 충족 요약
6. 최종 QA
7. 이미지 큐 상태 — `READY`

이 중 하나라도 빠지면 이미지 단계로 넘어가지 않습니다.

## 검수 구조

```text
작성
↓
독립 Reviewer
↓
Approval Gate
↓
FAIL이면 문제 단계로 반려
↓
수정
↓
재검수
↓
Inline Link Coverage Gate
↓
Final Control Tower
```

Requirement Ledger의 REQUIRED 항목이 하나라도 충족되지 않으면 최종 승인하지 않습니다.

## 체류와 수익화

체류는 반복이 아니라 추가 가치로 만듭니다.

- 비교
- 예외
- 실수 방지
- FAQ
- 체크리스트
- 공식 영상
- 실제 내부글
- 정보가 겹치지 않는 이미지

애드포스트 광고 클릭은 직접 유도하지 않습니다.
검색 유입·정독·스크롤·내부 이동·재방문·신뢰를 높이는 방향으로 운영합니다.

## 이미지 큐 사용법

글이 먼저 완성된 뒤 화면에:

```text
이미지 큐: READY
NEXT_IMAGE_INDEX: 1
```

상태가 나오면 다음 메시지로:

```text
이미지 시작
```

또는

```text
1
```

을 입력합니다.

그다음은 `다음`만 입력하면 됩니다.
