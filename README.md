# NAVER Blog Master Skill v3.5

네이버 블로그 글쓰기·운영을 위한 **AI 멀티에이전트 편집국 Skill**입니다.

사용자는 키워드 하나, 큰 주제 하나, 목적 한 줄, 또는 정리되지 않은 설명만 던져도 됩니다.

예:

```text
$naver-blog-master AUTO FULL
지금 조회수를 최대한 노릴 수 있는 주제를 찾아서 글을 완성해줘.
```

## v3.5 핵심 변화

v3.5는 **글 전달과 이미지 생성을 완전히 분리**합니다.

이전에는 `Publish Package → Auto Image Queue`가 같은 실행 안에 붙어 있어, 이미지 도구가 먼저 실행되면 글쓰기 블록이 화면에 제대로 전달되지 않을 수 있었습니다.

이제는 반드시:

```text
글 조사·검수
↓
Final Control Tower 승인
↓
발행용 글쓰기 블록 + 링크팩 + 이미지 계획 + QA를 사용자에게 완전 전달
↓
PUBLISH_PACKAGE_DELIVERED = TRUE
↓
다음 사용자 턴에서만 이미지 시작
```

순서로 동작합니다.

## 가장 중요한 규칙

- 글 요청이면 **글이 먼저**입니다.
- 같은 턴에서 이미지 생성 도구를 호출해 글이 사라지게 하지 않습니다.
- 이미지 생성은 다음 턴에서 `이미지 시작`, `1`, `다음`, `계속`으로 진행합니다.
- 한 번에 한 장씩 개별 생성합니다.
- ARTICLE_ID와 TOPIC_LOCK으로 현재 글 주제를 이미지에 고정합니다.
- 이전 글의 단풍·여행·맛집·제품 이미지 컨텍스트가 섞이면 즉시 FAIL 처리합니다.

## 최종 출력 계약

AUTO FULL의 첫 최종 응답에는 반드시 다음 7개가 있어야 합니다.

1. 최종 선정 결과
2. 발행용 글쓰기 블록
3. 검증 링크팩
4. 이미지 제작팩
5. 요구사항 충족 요약
6. 최종 QA
7. 이미지 큐 상태 — `READY`

이 중 하나라도 빠지면 이미지 단계로 넘어가지 않습니다.

## 검수 구조

```text
작성
↓
독립 Reviewer
↓
Approval Gate
↓
FAIL이면 문제 단계로 반려
↓
수정
↓
재검수
↓
Final Control Tower
```

Requirement Ledger의 REQUIRED 항목이 하나라도 충족되지 않으면 최종 승인하지 않습니다.

## 링크 원칙

기본은:

> 답은 초반에, 깊이는 중간에, 행동 링크는 후반에.

- URGENT — 오늘 마감·잔여석 등: 상단 10~25%
- STANDARD — 지도·예약·가입·신청: 후반 60~90%
- FACT-CHECK — 공식자료·통계·보도자료: 관련 설명 뒤 또는 후반
- INTERNAL — 실제 발행한 관련글만 중반 이후

필수 링크를 빼서 체류를 강제하지 않고, 외부 링크를 첫 줄부터 던져 이탈시키지도 않습니다.

## 체류와 수익화

체류는 반복이 아니라 추가 가치로 만듭니다.

- 비교
- 예외
- 실수 방지
- FAQ
- 체크리스트
- 공식 영상
- 실제 내부글
- 정보가 겹치지 않는 이미지

애드포스트 광고 클릭은 직접 유도하지 않습니다.
검색 유입·정독·스크롤·내부 이동·재방문·신뢰를 높이는 방향으로 운영합니다.

## 이미지 신뢰 원칙

실존 인물·연예인·방송·스포츠·여행지는 먼저 실제 자료를 조사합니다.

우선 후보:
1. 사용자 제공 이미지
2. 상업적 이용·변형 조건이 명확한 공식/공공 자료
3. 공공누리 0/1 유형
4. CC0 / Public Domain
5. CC BY 등 허용 라이선스
6. 명시적 재사용 허가 프레스킷

일반 뉴스사진·연예기사 사진·팬사진·SNS 사진은 공개돼 있다는 이유만으로 재사용하거나 재가공하지 않습니다.

웹에서 찾은 이미지를 현재 이미지 생성 도구가 직접 편집 입력으로 받지 못하는 환경에서는 실제 재가공했다고 주장하지 않습니다. 필요한 경우 허용된 원본을 현재 대화에 업로드한 뒤 편집합니다.

## 이미지 큐 사용법

글이 먼저 완성된 뒤 화면에:

```text
이미지 큐: READY
NEXT_IMAGE_INDEX: 1
```

상태가 나오면 다음 메시지로:

```text
이미지 시작
```

또는

```text
1
```

을 입력합니다.

그다음은 `다음`만 입력하면 됩니다.

현재 환경에서는 이미지 생성 후 텍스트 응답이 종료될 수 있으므로 **한 번의 사용자 명령으로 여러 장을 연속 생성한다고 약속하지 않습니다.** 대신 한 장씩 주제 검수하면서 안전하게 진행합니다.
