# Blog Master Skill v1.1

한국어 정보성 블로그를 위한 **주제 선정 → 자료조사 → 팩트체크 → 검색의도·SEO → 글쓰기 → 독립 재검증 → 공식 링크 → 정보형 이미지** 스킬입니다.

핵심 원칙은 하나입니다.

> **조사와 검증은 깊게, 최종 출력은 간결하게.**

자동화는 단계를 없애는 것이 아니라 사용자의 반복 입력을 줄이는 방식으로 동작합니다.

## 주요 명령

```text
새 글 자동 작성
```
새 정보성 주제를 선정해 1~5단계를 연속 수행합니다.

```text
오늘 시의성 높은 글 자동 작성
```
현재 날짜 기준 검색 필요성과 시의성이 높은 주제를 찾아 1~5단계를 수행합니다.

```text
다른 주제로 새 글 자동 작성
```
기존 주제를 버리고 주제 이력을 검사해 검색의도가 겹치지 않는 새 주제로 진행합니다.

```text
이미지 자동 진행
```
5단계에서 확정된 최종 원고만 기준으로 이미지 설계·생성 단계로 이동합니다.

## 1~6단계

1. **주제 선정·1차 조사** — 현재성, 계절성, 검색 필요성, 공식자료 확보 가능성, 중복 주제 검사
2. **검색의도·SEO·제목** — 메인/서브/롱테일 키워드, 실제 검색 질문, 최종 제목
3. **문단 설계** — 각 소제목이 검색 질문 하나에 답하도록 구조화
4. **게시용 원고 작성** — 최신 검증정보, 모바일 가독성, 행동 링크 포함
5. **독립 2차 팩트체크** — 날짜·숫자·조건·링크 재검증 + 최종 품질 게이트
6. **이미지 자동 진행** — 대표 1장 + 서로 다른 질문을 담당하는 본문 정보 이미지

## GitHub 검증 도구의 장점 적용

외부 프로그램을 필수 설치하지 않고, 다음 오픈소스 프로젝트의 검증 철학을 스킬 내부 게이트로 적용합니다.

- **Vale** — 문체·스타일 린트
- **textlint** — 모듈형 자연어 규칙 검사
- **lychee** — 깨진 링크·리다이렉트·목적지 검증
- **markdownlint-cli2** — 문서 구조·소제목·목록·형식 검사

5단계 마지막에는 다음 `FINAL FOUR-GATE`를 실행합니다.

```text
STYLE_LINT
→ TEXT_RULE_LINT
→ LINK_HEALTH (링크가 필요한 글)
→ STRUCTURE_LINT
```

FAIL 항목이 있으면 해당 부분을 직접 수정한 뒤 다시 검사합니다.

외부 바이너리 설치는 필수가 아닙니다. 설치되어 있다면 보조 검증으로 활용할 수 있지만, 없더라도 동일한 내부 품질 규칙을 수행합니다.

## 링크 출력 원칙

독자가 실제 신청·조회·예약·법령 확인 등을 해야 하는 글은 **일반 본문형 출력**을 기본으로 합니다.

이유는 일부 글쓰기 블록/복사 환경에서 외부 링크가 보존되지 않을 수 있기 때문입니다.

- 링크 문구와 실제 목적이 일치해야 합니다.
- 메인 홈페이지보다 직접 행동 페이지를 우선합니다.
- 링크가 실제로 렌더링되지 않았다면 `링크 포함 완료`로 판정하지 않습니다.
- 링크가 필요 없는 글은 편집 가능한 글쓰기 블록을 사용할 수 있습니다.

## 품질 기준

내부 평가는 다음 기준으로 100점 만점입니다.

- 팩트 정확성 20
- 최신성 15
- 검색의도 15
- 제목·본문 일치 10
- 구조 10
- 한국어 자연스러움 10
- 모바일 가독성 10
- 정보 전달력 10

**85점 미만이면 수정 후 다시 검토**합니다. 점수는 사용자가 요청하지 않으면 출력하지 않습니다.

## 핵심 원칙

- 키워드를 위한 글을 쓰지 않습니다.
- 전년도 자료의 연도만 바꾸지 않습니다.
- 최대값을 일반값처럼 쓰지 않습니다.
- 예정을 확정처럼 쓰지 않습니다.
- 모르는 내용을 채워 넣지 않습니다.
- 출처와 독자용 행동 링크를 구분합니다.
- 이미지에 최종 원고 밖 정보를 추가하지 않습니다.
- 새 규칙이 추가되어도 **1~6단계 핵심 기능은 삭제하지 않고 보완**합니다.
